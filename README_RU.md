### 🎯 Основные принципы

* **SWAG остаётся движком** — `swag-ui` управляет им и предоставляет удобный интерфейс, но не заменяет SWAG.
* **`/config` — единственный источник истины** — панель не создаёт отдельную базу состояния.
* **Docker-first** — рассчитана на использование SWAG в Docker.
* **Безопасное применение изменений** — перед reload конфигурация проверяется через `nginx -t`.
* **Безопасный доступ к Docker** — операции с Docker изолированы через ограниченный `swag-guard`.
* **Минимальный размер** — Docker-образ занимает около **9 МБ**.
* **Простое восстановление** — удаление и повторная установка панели не требуют восстановления её собственной базы данных.
* **Свобода для продвинутых пользователей** — остаётся доступ к raw-конфигурации и универсальной настройке DNS-провайдеров.
